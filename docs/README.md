# docs/ — documentos y entregables

| Archivo o carpeta | Qué es |
|---|---|
| `politicas/` | Las políticas de la distribuidora (devoluciones, entregas, pagos). Son los documentos que busca `buscar_documentos`. |
| `conversaciones/` | Las 5 conversaciones de ejemplo con su traza de pasos. Se regeneran con `make demo`. |
| `grafo.mmd` | El diagrama del grafo en Mermaid. Se regenera con `make grafo`. |
| `decisiones.md` | Por qué un agente y no un flujo fijo, qué acciones piden aprobación y cómo se eligió el límite de pasos. |
| `bitacora_asistente.md` | Plantilla para la bitácora del asistente de código (3 prompts y 1 error corregido). |
